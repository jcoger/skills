# Tag Taxonomy

Four tag groups. Every entry carries all four. Values come only from these lists. EXTRACT and CURATE may PROPOSE additions in their approval output; nothing is added silently.

## archetype (business kind: 1 required, a second allowed)

`saas` `dtc` `fintech` `health` `app` `studio` `launch` `b2b-services`

## domain (move kind: exactly 1)

`layout` `type` `imagery` `background` `art-direction` `motion` `interaction` `proof` `navigation`

Disambiguation: `art-direction` is for whole-visual-system moves (a treatment applied everywhere); `imagery` is for moves about specific images; `interaction` is input-driven (scroll, cursor, tap); `motion` is time-driven (autonomous animation).

## mood (1 required, a second allowed)

`grounded` `kinetic` `editorial` `playful` `immersive`

These deliberately match the motion-direction personality names, so a project with an approved motion personality can FIND by mood without translation.

## cost (exactly 1)

`S` under 2 hours · `M` 2 to 6 hours · `L` over 6 hours

Cost is implementation effort for a competent builder with the move's assets in hand, not including asset production.

## Reserved: page-type tags

Page-type tags (pricing, comparison, lander, blog, case-study, careers, etc.) pair with the marketing-site-architecture skill: add them here as that skill's page-type recipes are used against the library. Keep the vocabulary aligned with marketing-site-architecture's page types rather than improvising synonyms.
