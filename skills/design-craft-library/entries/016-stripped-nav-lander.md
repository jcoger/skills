# 016 - Stripped nav lander
- **Source:** intercom.com paid landers (observed 2026-06)
- **Tags:** archetype: saas · domain: navigation · mood: grounded · cost: S
- **What:** A dedicated paid-traffic lander where navigation is reduced to logo plus a single CTA: no menu, no footer link farm. The page is a one-way corridor.
- **Use when:** paid traffic with one conversion goal, where message match with the ad matters more than exploration. **Skip when:** organic landing pages; stripping nav there hurts orientation and SEO.
- **Why it works:** every removed link is a removed exit. Nav removal is one of the most reliable lander conversion lifts available.
- **Build owner:** marketing-site-architecture (lander recipe) with the conversion skill.
- **Do not copy:** hiding pricing or legally required links entirely.
- **Cost:** S (under 2h)
