# 014 - Case study cover grid
- **Source:** koto.com (observed 2026-06)
- **Tags:** archetype: studio · domain: layout · mood: editorial · cost: M
- **What:** A work index treated like a magazine rack: each case study gets a designed cover (full-bleed image, oversized title lockup) instead of a uniform thumbnail card.
- **Use when:** the portfolio is the product (studios, agencies) and each project has strong, distinct art. **Skip when:** the work is visually samey; covers expose it.
- **Why it works:** covers promise the work inside got the same care. Uniform thumbnail grids promise the opposite.
- **Build owner:** marketing-site-architecture (case-study index recipe) with marketing-page-layout.
- **Do not copy:** covers that hide the project name and category; orientation beats theater.
- **Cost:** M (2 to 6h)
