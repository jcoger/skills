# 007 - Scroll step theater
- **Source:** common on product-led SaaS sites (observed 2026-06)
- **Also seen:** paraform.com (observed 2026-06), the pinned frame cross-fades the *entire* left column (headline + copy + an embedded display-stat) alongside a per-state product-UI collage, stepped by a segmented progress pill, with an opening state that adds a testimonial card.
- **Tags:** archetype: saas · domain: interaction · mood: immersive · cost: L
- **What:** A pinned viewport where product UI stays in place while scroll steps swap annotations, states, or zoom levels around it.
- **Use when:** the product has a flow worth narrating in 3 to 5 steps and the UI is genuinely the proof. **Skip when:** the UI is weak, the steps exceed 5, or the build budget is tight.
- **Why it works:** turns scrolling into a guided demo where the user controls the pace, which reads as honesty; the strongest possible use of a sticky shape.
- **Build owner:** marketing-page-layout composes; motion-direction owns triggers and counts it against the one-pin budget.
- **Do not copy:** hijacked or slowed scroll; the user's scroll speed is sacred.
- **Cost:** L (over 6h)
