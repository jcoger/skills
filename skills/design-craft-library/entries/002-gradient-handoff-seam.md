# 002 - Gradient handoff seam
- **Source:** stripe.com (observed 2026-06)
- **Tags:** archetype: saas · domain: background · mood: grounded · cost: S
- **What:** Two adjacent sections share one gradient that crosses the boundary between them, so the seam is a designed element instead of a hard cut.
- **Use when:** consecutive sections share a narrative thread and the page risks feeling like stacked rectangles. **Skip when:** sections need clear separation or backgrounds already alternate.
- **Why it works:** kills the stacked-slides feel and carries scroll momentum across the boundary; the background system does narrative work for free.
- **Build owner:** marketing-page-layout (background systems).
- **Do not copy:** the signature color ramps verbatim; derive the ramp from the project palette.
- **Cost:** S (under 2h)
