# 022 - Inside-card proportion: text block over fragment
- **Source:** audyr.com (observed 2026-06)
- **Tags:** archetype: saas · domain: type · mood: grounded · cost: S
- **What:** Every "frame" card follows one proportion: a tight TEXT block on top (a title + a 2-line body, grouped) and a product FRAGMENT anchored below (a row list, a mini flow, status pills, a small chart). A clear gap separates the two. The fragment has its own nested cells at ONE consistent small size.
- **Use when:** building any grid/bento of feature cards where each card explains one thing and shows a glimpse of it. **Skip when:** the card is a pure object (full-bleed visual) or pure text (a quote).
- **Why it works:** the fixed text-then-fragment rhythm makes a grid of varied cards feel like one system. The discipline is in the type: a card title is NOT a section heading. It draws from a dedicated small in-card ramp (title / body / label), so nested text never collapses and never competes with section H2s.
- **The rule it encodes:** in-card text gets its own ramp, derived from a gentle *below-base* ratio (a single type ratio steep enough for a good display collapses the small end). Card emphasis comes from card SIZE in the grid, not bigger text.
- **Build owner:** marketing-page-layout + the Card type ramp (--text-card-title / -body / -label / -stat).
- **Do not copy:** letting an oversized anchor cell inflate its title. Keep the ramp; let the slot size carry the weight.
