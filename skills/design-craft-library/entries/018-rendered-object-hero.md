# 018 - Rendered object hero
- **Source:** cash.app (observed 2026-06)
- **Tags:** archetype: fintech · domain: imagery · mood: kinetic · cost: L
- **What:** A 3D-rendered brand object (card, coin, device) as the hero centerpiece, slowly rotating or physics-reactive, replacing photography and UI entirely.
- **Use when:** the brand has one iconic, ownable object and consumer energy. **Skip when:** no real object exists (an abstract blob is not an object) or the load budget is tight.
- **Why it works:** a rendered object is infinitely art-directable and reads as brand wealth; its motion becomes the signature moment by default.
- **Build owner:** marketing-page-layout composes; motion-direction owns rotation and physics against the motion budget.
- **Do not copy:** heavy uncompressed 3D files; past roughly 1.5MB the move costs more than it earns.
- **Cost:** L (over 6h)
