# Story Patterns

Fourteen archetypes for product animations. Each is a proven story shape: a claim type it proves, a beat skeleton, an emotional beat, a loop strategy, and a build risk. Use the picker first, then read the shortlisted entries.

## Claim-to-archetype picker

| Claim type | Archetypes to shortlist |
|---|---|
| Precision / prevention ("we catch what others miss") | The Near Miss, The Scan, The Gauntlet |
| Speed ("we are faster") | The Race, The Time-Lapse, The Domino |
| Control / visibility ("chaos becomes clarity") | The Collapse, The Sorter, The Live Feed |
| Automation / effort removed ("we do the work") | The Handoff, The Domino, The Assembly |
| Reliability / trust ("always on, never flinches") | The Stress Test, The Heartbeat, The Gauntlet |
| Transformation ("the old way becomes the new way") | The Morph, The Time-Lapse, The Collapse |

## The archetypes

### 1. The Near Miss
- **Story:** Something moves smoothly toward disaster. At the last second, the product catches it.
- **Skeleton:** smooth progress (1s) -> sudden pause, slight rewind (1s) -> the flaw revealed (1s) -> correction (1s) -> payoff stat (1s) -> outcome, next item enters (1s).
- **Emotion:** relief. **Signature:** the pause-and-catch. **Loop:** conveyor reset. **Risk:** low; the drama is timing, not rendering.
- The pause is the whole archetype. Hold it slightly longer than comfortable.

### 2. The Race
- **Story:** Two processes start together. Ours finishes while the other is still grinding.
- **Skeleton:** both start (1s) -> parallel progress, paces diverge (2s) -> ours finishes, theirs continues (1s) -> the gap becomes visceral (1.5s) -> theirs limps in, delta stated (1s) -> reset (0.5s).
- **Emotion:** victory. **Signature:** our side done while theirs still counts. **Loop:** counter reset. **Risk:** low; mostly type and counters.
- The craft is the dead air after we finish: let the viewer watch the other side keep going.

### 3. The Collapse
- **Story:** Several messy, disconnected things compress into one clean thing.
- **Skeleton:** the chaos, offset and fragmented (1.5s) -> pieces slide toward each other (1s) -> merge moment (0.5s) -> the clean unified view populates (2s) -> outcome line (1s).
- **Emotion:** relief. **Signature:** the merge instant. **Loop:** next messy stack enters. **Risk:** medium; the merge needs careful overlap to not read as a glitch.

### 4. The Gauntlet
- **Story:** One item passes through visible checkpoints, each verified in rhythm.
- **Skeleton:** item enters, gates visible ahead (1s) -> checkpoint 1 pause + pass (1s) -> checkpoint 2 (1s) -> checkpoint 3 (1s) -> final state with all checks visible (1s) -> exit, next enters (1s).
- **Emotion:** confidence. **Signature:** the third check landing. **Loop:** conveyor reset. **Risk:** low.
- The rhythm of pause-check-continue is the point; do not rush the pauses. Reads as luxury-manufacturing thoroughness.

### 5. The Scan
- **Story:** A beam sweeps the artifact; hidden flaws light up, then fix themselves in sequence.
- **Skeleton:** clean-looking artifact (1s) -> beam sweeps slowly (2s) -> flaws revealed, pulsing (1s) -> tension hold (0.5s) -> sequential corrections (1s) -> clean state plus stat (0.5s).
- **Emotion:** satisfaction. **Signature:** the beam mid-sweep with the first flaw igniting. **Loop:** next artifact enters for scanning. **Risk:** medium; the beam must feel methodical, not decorative.
- Strongest when the claim is a capability competitors lack; the scan shows the invisible work.

### 6. The Assembly
- **Story:** Scattered pieces fly in and build the finished result.
- **Skeleton:** parts scattered or entering (1s) -> pieces fly to position in waves (2s) -> final piece clicks (0.5s) -> the whole comes alive (1.5s) -> outcome (1s).
- **Emotion:** delight. **Signature:** the last piece clicking in. **Loop:** disassemble in reverse fast, or next build begins. **Risk:** high in Lottie if pieces are many; cap movers per wave.

### 7. The Time-Lapse
- **Story:** A long painful timeline compresses into seconds; the product collapses time itself.
- **Skeleton:** the old timeline begins crawling (1.5s) -> accelerates, milestones flicker past (1.5s) -> hard cut to the product's short path (1s) -> side-by-side delta (1.5s) -> outcome (1s).
- **Emotion:** victory. **Signature:** the hard cut. **Loop:** counter reset. **Risk:** low.

### 8. The Live Feed
- **Story:** A stream of real work scrolls by, getting handled item by item. The system is alive.
- **Skeleton:** feed flowing (1.5s) -> camera settles on one item (1s) -> it resolves with a satisfying state change (1s) -> zoom back, the stream continues, counts tick up (1.5s) -> loop seamlessly (1s).
- **Emotion:** confidence. **Signature:** the single item resolving. **Loop:** ambient, no reset needed. **Risk:** medium; needs believable variety in the feed items.

### 9. The Morph
- **Story:** The old painful artifact physically transforms into the new one.
- **Skeleton:** the old thing, in all its mess (1.5s) -> transformation begins at one corner (1s) -> the morph sweeps through (1.5s) -> the new thing settles (1s) -> outcome (1s).
- **Emotion:** satisfaction. **Signature:** the morph mid-sweep, half old half new. **Loop:** next old artifact enters. **Risk:** high; morphs are the hardest mover to build well. Name the fallback (crossfade with a wipe).

### 10. The Stress Test
- **Story:** Load piles on. The product does not flinch.
- **Skeleton:** normal state (1s) -> volume ramps, visibly heavy (1.5s) -> the moment it should break, it doesn't (1s) -> steady metrics hold (1.5s) -> volume drains, calm (1s).
- **Emotion:** confidence. **Signature:** the should-break moment holding steady. **Loop:** ambient ramp cycle. **Risk:** medium.

### 11. The Handoff
- **Story:** Work passes from a person to the product, and the effort visibly disappears.
- **Skeleton:** a person mid-tedium (1s) -> one gesture hands it off (1s) -> the product churns through it at machine pace (1.5s) -> done lands back, human moves to real work (1.5s) -> outcome (1s).
- **Emotion:** relief. **Signature:** the pace shift at the handoff. **Loop:** next task appears. **Risk:** low.

### 12. The Domino
- **Story:** One small input cascades into many finished outcomes.
- **Skeleton:** a single tap or entry (1s) -> first consequence fires (0.5s) -> the cascade fans out (1.5s) -> the full set of outcomes lands (1.5s) -> tally stated (1s).
- **Emotion:** delight. **Signature:** the fan-out frame. **Loop:** outcomes clear, next input arrives. **Risk:** medium; cap the cascade or it becomes noise (one mover per beat still applies, the cascade is one mover).

### 13. The Sorter
- **Story:** A chaotic stream gets classified into tidy lanes in real time.
- **Skeleton:** mixed stream flowing (1.5s) -> the sorter engages, items begin routing (1.5s) -> lanes fill, each labeled (1.5s) -> one tricky item gets caught and routed correctly (1s) -> steady state (0.5s).
- **Emotion:** satisfaction. **Signature:** the tricky item routing. **Loop:** ambient stream. **Risk:** medium.

### 14. The Heartbeat
- **Story:** No plot, just presence: the system breathing, always on, quietly working.
- **Skeleton:** ambient pulse (2s) -> a small event handled without drama (1.5s) -> return to pulse (1.5s). Total loop 4 to 6s.
- **Emotion:** confidence. **Signature:** the event absorbed without a ripple. **Loop:** ambient by nature. **Risk:** low, but B3 is waived only for trust claims; this is the one archetype allowed to be calm instead of tense, and it must say so explicitly.

## Combination rules

- Archetypes stack, maximum two. A Scan inside a Gauntlet (one checkpoint is a scan) works. Three archetypes is three stories, which is zero stories.
- When stacking, one archetype owns the structure and the other owns a single beat.
- The emotional beat comes from the structural archetype, never both.

## Ending discipline

Every archetype ends with a human or business outcome before the loop reset: who benefits, stated in one line or one image. The stat is the proof; the outcome is the point. Then the reset happens inside the fiction (B5).
